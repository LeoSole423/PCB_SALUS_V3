# Archivo histórico

Material separado del proyecto activo el 15/10/2026. No se eliminó contenido.

- `v2/`: PCB y esquema raíz heredados. Son fragmentos, no un proyecto autónomo:
  el esquema referenciaba las hojas ESP32 y SENSORES de la raíz original.
  Para reconstruir la revisión usar su historial Git y bibliotecas correspondientes.
- `hojas-sin-uso/`: hoja vacía `01_ALIMENTACION.kicad_sch`, no referenciada
  por el esquema activo.
- `respaldos/`: respaldo de restauración del 03/08/2026, conservado sin cambios.
- `exportaciones-toolkit/production/`: exportación antigua `pcb_test`.
  `pcb_test_positions.csv` sigue siendo la referencia de las pruebas CPL;
  no usar este paquete para el pedido vigente.

Los archivos conservan sus bytes originales; las rutas antiguas pueden aparecer
como metadatos históricos dentro de informes o respaldos. No son rutas operativas.
